# image-analysis-processing-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `image-analysis-processing`.

Run the server:

```bash
cargo run -p image-analysis-processing-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/image-analysis-processing-app dev
```
