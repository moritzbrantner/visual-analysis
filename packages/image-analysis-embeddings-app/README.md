# image-analysis-embeddings-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `image-analysis-embeddings`.

Run the server:

```bash
cargo run -p image-analysis-embeddings-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/image-analysis-embeddings-app dev
```
