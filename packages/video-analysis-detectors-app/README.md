# video-analysis-detectors-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-detectors`.

Run the server:

```bash
cargo run -p video-analysis-detectors-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-detectors-app dev
```
