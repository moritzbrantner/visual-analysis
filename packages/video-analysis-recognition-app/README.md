# video-analysis-recognition-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-recognition`.

Run the server:

```bash
cargo run -p video-analysis-recognition-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-recognition-app dev
```
