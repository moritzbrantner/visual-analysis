# image-analysis-detection-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `image-analysis-detection`.

Run the server:

```bash
cargo run -p image-analysis-detection-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/image-analysis-detection-app dev
```
