# video-analysis-segmentation-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-segmentation`.

Run the server:

```bash
cargo run -p video-analysis-segmentation-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-segmentation-app dev
```
